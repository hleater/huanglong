# 创业板短线选股分析

系统化的A股创业板短线选股工作流，基于热点赛道研判、主力资金流向分析、游资/散户资金结构分析，推荐适合短期操作的创业板（300xxx）股票。

## When to Use

- 用户要求推荐A股短线操作的个股
- 用户要求分析主力/游资/散户的资金结构
- 用户要求基于当前市场热点推荐标的
- 用户需要创业板（300开头）标的推荐
- 用户需要格式化股票分析报告

## Workflow

### Step 1: 梳理当前A股市场热点赛道

通过web_search搜索以下维度，梳理当前A股核心热点：

```text
搜索1: "A股 热点 板块 领涨 202X年X月"
搜索2: "创业板 半导体 AI 机器人 光模块 新能源 领涨 202X年X月"
搜索3: "A股 主力资金 净流入 板块排名 202X年X月"
搜索4: "[具体赛道关键词] 概念 大涨 202X年X月"
```

**近期典型热点赛道参考（持续更新）：**
- 🧠 **半导体/AI算力** — 芯片、光模块（CPO）、PCB、存储
- 🤖 **机器人/物理AI** — 人形机器人、伺服系统、控制器
- 🔋 **新能源/储能** — 光伏逆变器、储能系统、AIDC
- 💎 **新材料** — 培育钻石、MLCC、稀土永磁
- 🔌 **算力硬件** — PCB、高速铜连接、服务器

### Step 2: 筛选创业板（300xxx）潜在标的

基于热点赛道筛选符合条件的创业板股票：

1. **股票代码必须以300开头**（创业板）
2. 股价不宜过高（避免高价股，短线资金博弈门槛）
3. 成交活跃（日成交额 > 5亿元为佳）
4. 所属赛道与当前热点高度重合

搜索具体标的的资金数据：
```text
搜索: "[股票名称] [股票代码] [月份] 成交额 主力资金 游资 散户 资金流向"
搜索: "[股票名称] [股票代码] [月份] 股价 涨幅"
```

### Step 3: 获取关键交易数据（统一格式）

对每支推荐标的，采集以下数据：
- **股价**：当日收盘价及涨跌幅
- **成交额**：单日/半日成交金额
- **资金流入/流出**：总流入、总流出、净流入
- **主力资金**：特大单净流入金额及占比
- **游资资金**：大单净流入金额及占比
- **散户资金**：中小单净流入金额及占比

数据来源优先级：
1. 同花顺资金流向页面（stockpage.10jqka.com.cn）
2. 新浪财经个股行情页面（finance.sina.com.cn/realstock）
3. 东方财富资金流向页面（quote.eastmoney.com）
4. 21经济网/华尔街见闻等财经媒体资金周报

### Step 4: 资金结构分析

根据采集的资金流向数据，进行三分类分析：

| 资金类型 | 定义 | 常见特征 |
|:-------:|:----|:--------|
| **主力** | 特大单（≥500万元/笔） | 机构主导，持续流入=系统性建仓 |
| **游资** | 大单（100-500万元/笔） | 短线炒作，快进快出，活跃度高 |
| **散户** | 中小单（<100万元/笔） | 跟风型，方向通常滞后于主力 |

**定性判断标准：**
- 主力净流入占比>50% → **主力主导型上涨**（机构行情）
- 游资净流入占比高 → **游资博弈型**（短线机会大但波动也大）
- 散户买入占比高且主力流出 → **散户接盘型**（警惕回调风险）

### Step 5: 撰写推荐理由（统一格式）

按以下维度输出推荐理由表格：

| 维度 | 分析内容 |
|:---:|---------|
| **🔥 风口** | 所属赛道热度、行业逻辑、核心催化剂 |
| **📈 业绩** | 近期财务数据、业绩增速、增长逻辑 |
| **💰 资金** | 主力资金流向分析、成交活跃度 |
| **🏛️ 催化剂** | 近期事件驱动（调入指数、政策利好、新产品等） |
| **📊 研报** | 机构观点、目标价、评级 |

### Step 6: 输出标准化报告（格式统一规则 ⚠️ 关键）

**三支推荐的输出格式必须完全一致**，不能出现推荐一、推荐二格式不同。每一支推荐都使用完全相同的段落结构和表头。具体规定如下：

**① 关键交易数据** — 使用完整格式（包含总流入/总流出）：
```
| 指标 | 数值 |
|:---|:----:|
| **股价** | **XXX元** 📈 |
| **当日涨幅** | **+X.XX%**（+XX.XX元） |
| **成交额** | **XX亿元** |
| **总资金流入** | XX亿元 |
| **总资金流出** | XX亿元 |
| **资金净流入** | **+XX亿元** 🔥 |
```

**② 资金结构分析** — 使用精简表（仅净额+占比估算，带定性判断）：
```
| 资金类型 | 净额 | 占比估算 |
|:-------:|:---:|:--------:|
| **主力（特大单）** | **+XX亿元** 🟢 | **~XX%** |
| **游资（大单）** | +/-XX亿元 | **~XX%** |
| **散户（中小单）** | +/-XX亿元 | **~XX%** |

> 📌 **定性**：[主力主导型/游资博弈型/散户接盘型] — [分析一句话]
```

**③ 推荐理由** — 使用五维度表（风口/业绩/资金/催化剂/研报）：
```
| 维度 | 分析 |
|:---:|------|
| **🔥 风口** | ... |
| **📈 业绩** | ... |
| **💰 资金** | ... |
| **🏛️ 催化剂** | ... |
| **📊 研报** | ... |
```

**④ 风险提示** — 统一使用无序列表（每支股票必须至少2条）：
```
### ⚠️ 风险提示
- ...
- ...
```

在报告末尾增加对比表和策略建议：

| 维度 | 🥇 [股票A] | 🥈 [股票B] | 🥉 [股票C] |

| **短线弹性** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 数据库存储

数据库路径：`/root/.hermes/stock_recommendations.db`

### 表结构

```sql
CREATE TABLE stock_recommendations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    stock_code TEXT NOT NULL,       -- 股票代码
    stock_name TEXT NOT NULL,       -- 股票名称
    recommend_date TEXT NOT NULL,   -- 推荐日 (YYYY-MM-DD)
    recommend_price REAL NOT NULL,  -- 推荐日股价
    current_date TEXT,              -- 当前日期 ✅ (YYYY-MM-DD)
    current_price REAL,             -- 当前股价
    change_pct REAL,                -- 涨幅 (%)
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 字段说明

| 字段名 | 中文名 | 说明 |
|:------|:------|:----|
| `recommend_date` | **推荐日** | 你推荐这支股票的日期 |
| `recommend_price` | **推荐价** | 推荐当日的收盘价 |
| `current_date` | **当前日期** | 最新更新股价时的日期 ✅ 已存在 |
| `current_price` | **当前价** | 最新更新时的股价 |
| `change_pct` | **涨幅** | `(当前价 - 推荐价) / 推荐价 × 100%` |

### 查询结果展示规则

`list` 和 `summary` 命令的输出以**表格形式**展示，涨幅字段颜色规则：

| 涨幅范围 | 颜色 | 含义 |
|:-------:|:----:|:----:|
| > 0 | 🔴 **红色** | 上涨盈利 |
| < 0 | 🟢 **绿色** | 下跌亏损 |
| = 0 | ⚫ 默认色 | 持平 |
| 待更新 | ⚪ 文字"待更新" | 还未填入当前价 |

示例输出格式：
```
ID   代码      名称       推荐日       推荐价     当前日期    当前价    涨幅    状态
================================================================================
1    300476  胜宏科技    2026-05-22  375.50    待更新      待更新   待更新   ⏳待更
```

当用户再次调用本技能（非首次推荐，而是查询/更新之前推荐的股票表现时），执行以下流程更新数据库中已有记录的当前股价和涨幅：

## Pitfalls

1. **创业板代码识别**：必须以300开头才是创业板（002开头=中小板，688开头=科创板）
2. **数据时效性**：资金流向数据为T日数据，盘后约1-2小时更新，短线操作需关注次日的资金变化
3. **资金流向≠股价方向**：主力资金净流入不代表次日必涨，需结合技术面判断
4. **高价股流动性风险**：股价>500元的创业板个股，散户参与度低，短线波动可能较大
5. **同花顺/东方财富页面可能被屏蔽**：部分金融数据页面需要L2权限才能查看完整资金流向
6. **21经济网等财经媒体有付费墙**：部分深度报告需要付费阅读，优先用搜索获取摘要
7. **主力资金大幅流出是危险信号**：单周主力净流出>20亿元应高度警惕（如光模块板块已出现大规模出货）
8. **港股通调入事件**：股票调入港股通后通常有增量资金，是短线重要催化剂
