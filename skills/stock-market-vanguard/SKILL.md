# 股市先锋 - Stock Market Vanguard

## 概述

本技能专注于 A 股短线热点追踪与分析，帮助用户识别市场热点板块、挖掘短线潜力股。

## 核心功能

1. **热点板块分析** - 识别当日强势板块、资金流入方向
2. **涨停股筛选** - 从涨停股中筛选具有持续性的标的
3. **推荐输出** - 3-5 只股票 + 代码 + 板块 + 价格 + 资金流向（占比+金额）+ 理由
4. **历史记录** - 每次分析结果存档，支持回溯
5. **追踪报表** - 统计历史推荐股票从推荐日到今日的涨跌表现

## 工作流程

### Step 1: 获取今日市场热点数据（必须）

使用东方财富涨停板接口获取当日涨停股票列表：

```powershell
# 获取今日涨停股票（按涨停时间排序，取前20只）
# ⚠️ fs 参数排除科创板(688)和北证：只保留创业板(300)、深市主板(000/002)、沪市主板(600/601/603)
#   m:0+t:6  = 深交所创业板(300)
#   m:0+t:80 = 深交所主板(000/002)
#   m:1+t:2  = 上交所主板(600/601/603)
#   不包含 m:1+t:23(科创板688) 和 北证板块
powershell -Command "Invoke-RestMethod -Uri 'https://push2.eastmoney.com/api/qt/clist/get?cb=jQuery&fid=f3&po=1&pz=20&pn=1&np=1&fltt=2&invt=2&ut=b2884a393a59ad64002292a3e90d46a5&fields=f12,f14,f2,f3,f62,f184&fs=m:0+t:6,m:0+t:80,m:1+t:2' -TimeoutSec 15"
```

**返回数据解析：**
- f12 = 股票代码
- f14 = 股票名称
- f2 = 最新价
- f3 = 涨跌幅（%）
- f62 = 成交量
- f184 = 主力净流入占比（%）

**同时搜索今日热点新闻：**
```
搜索关键词：
- "今日 A 股涨停板 热点题材"
- "今日强势股 龙头股"
- "今日资金流入板块"
```

### Step 2: 分析热点板块

从涨停股票列表中识别热点板块：
1. 统计涨停股所属板块（行业、概念）
2. 识别板块内涨停家数（超过 3 家为强热点）
3. 结合新闻判断热点持续性

### Step 3: 筛选推荐股票（必须使用新股票）

⚠️ **重要：每次推荐必须选择新的股票，不能重复推荐历史股票！**

筛选条件：
1. **当日涨停或涨幅 > 5%**
2. **流通市值 50 亿以下**（短线弹性大）
3. **属于当前热点板块**（板块内涨停 ≥ 3 家）
4. **有明确涨停原因或题材**
5. **不能在历史推荐中出现**（避免重复）
6. **⚠️ 排除科创板（688开头）和北证/北交所（8开头、4开头）**

筛选优先级：
- 首选：当日涨停 + 板块热点强 + 主力净流入
- 次选：涨幅 > 5% + 板块热点 + 放量明显

### Step 4: 获取个股实时行情（必须）

**两步操作：①价格行情 → ②资金流向**

#### 4.1 价格行情（新浪财经接口）

```powershell
powershell -Command "Invoke-RestMethod -Uri 'https://hq.sinajs.cn/list=sh新股票代码1,sh新股票代码2,sz新股票代码3' -Headers @{'User-Agent'='Mozilla/5.0';'Referer'='https://finance.sina.com.cn'} -TimeoutSec 15"
```

**参数说明：**
- `sh` = 上交所股票前缀
- `sz` = 深交所股票前缀

**返回数据解析：**
- 数据格式：`var hq_str_sh{代码}="名称,今开,昨收,现价,最高,最低,..."`
- 索引 1 = 今开，索引 2 = 昨收，索引 3 = 现价
- 涨跌额 = 现价 - 昨收
- 涨跌幅 = (涨跌额 / 昨收) × 100%

#### 4.2 资金流向（东方财富接口）

```powershell
# 单只股票（secid = 市场代码.股票代码）
# 上交所: 1.{代码}  深交所: 0.{代码}
powershell -Command "Invoke-RestMethod -Uri 'https://push2.eastmoney.com/api/qt/stock/get?ut=fa5fd1943c7b386f172d0968e6433c6&invt=2&fltt=2&fields=f12,f14,f2,f3,f62,f184,f185,f186,f187,f188&secid=1.新股票代码' -TimeoutSec 15"
```

**资金流向字段含义：**

| 字段 | 含义 | 说明 |
|------|------|------|
| f184 | 超大单净流入占比（%） | 超大单 = 成交额 ≥ 100万 |
| f185 | 大单净流入占比（%） | 大单 = 成交额 20-100万 |
| f186 | 中单净流入占比（%） | 中单 = 成交额 5-20万 |
| f187 | 超大单净流入额（万元） | 正=流入 负=流出 |
| f188 | 大单净流入额（万元） | 正=流入 负=流出 |

**资金分类计算：**
```
主力资金净流入占比  = f184(%) + f185(%)    ← 超大单+大单合计占比
主力净流入额（万元）= f187 + f188
游资资金净流入占比  = f186(%)
散户资金净流入占比  = 100 - |主力占比| - |游资占比|（估算）
```

🥈 {热点2}（{涨停家数}家涨停）
🥉 {热点3}（{涨停家数}家涨停）

【短线推荐】(3-5只)

   所属热点：{热点板块}
   当前价：{价格} 元 | 涨跌额：{涨跌} 元
   ─── 资金流向 ───
   🏅 主力资金：{主力占比}%（净流入 {主力金额} 万元 ↑）
   💰 游资资金：{游资占比}%（{游资金额} 万元 ↑↓）

### Step 5.1: 生成历史追踪报表

每次生成报告时，自动读取 `references/history/` 下所有历史文件，汇总历史推荐股票的当前表现：

**报表格式：**
```
📈 历史推荐股票追踪报表

| 代码 | 名称 | 推荐日 | 推荐价 | 统计日 | 当前价 | 涨跌幅 |
|------|------|--------|--------|--------|--------|--------|
| 601857 | 中国石油 | 04-02 | 12.35 | 04-08 | 12.34 | -0.08% |
| 600309 | 万华化学 | 04-02 | 82.71 | 04-08 | 85.89 | +3.85% |
| 688981 | 中芯国际 | 04-02 | 93.20 | 04-08 | 99.56 | +6.82% |

📊 本周战绩：已统计 3 只 | 盈利 2 只 | 胜率 66.67%
```

### Step 6: 记录历史

将分析结果保存到 `references/history/` 目录：

```
references/history/
├── 2026-04-02.md
├── 2026-04-03.md
└── ...
```

历史文件格式：

```markdown
# {日期} 市场分析

## 今日热点
- 热点1：{板块} - {简评}
- 热点2：{板块} - {简评}

## 推荐股票
1. {代码} {名称} - {所属热点}
   现价：{价格} | 涨幅：{涨幅}%
   主力：{主力占比}% | 游资：{游资占比}% | 散户：{散户占比}%
   理由：{推荐理由}

## 市场情绪
{整体市场氛围描述}

---
分析时间：{timestamp}
```

## 股票代码格式

- 上交所：`600XXX`、`601XXX`（主板）
- 深交所：`000XXX`（主板）、`002XXX`（中小板）、`300XXX`（创业板）
- ⚠️ **排除**：`688XXX`（科创板）、`8XXXX`/`4XXXX`（北证/北交所）

## 注意事项

1. **每次必须筛选新股票**：禁止重复推荐历史股票，必须从当日热点中筛选新标的
2. **信息时效性**：开盘前分析用前一日数据，盘中分析用实时数据
3. **风险控制**：每只股票都要提示风险，特别是高位股
4. **分散投资**：建议单只仓位不超过总资金的 20%
5. **止损意识**：短线建议设置 5-8% 止损线
6. **合规提醒**：本技能仅提供信息参考，不构成投资建议
7. **资金流向参考**：主力持续流入的股票短线爆发力更强

## 推荐理由参考模板

- "板块龙头，连板概率大"
- "消息面利好刺激，短期有望延续"
- "底部放量，突破关键位置"
- "资金持续流入，主力建仓明显"
- "超跌反弹，短线博弈机会"
- "主力净流入居前，机构主导拉升"

## 历史查询

当用户问及历史分析时，读取 `references/history/` 下对应日期的文件。
